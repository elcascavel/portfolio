# Context
Achievements.SA is a plugin for Grand Theft Auto: San Andreas that adds a fully featured achievement system to the game. Built entirely with plugin-sdk, it hooks into the game's native systems to detect player actions, track progress, and unlock achievements in real time without modifying the original game files.
